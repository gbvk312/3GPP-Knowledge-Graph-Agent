# TS 38.321 — NR; Medium Access Control (MAC) protocol specification

**3GPP Release:** Rel-18
**Version:** 18.2.0
**Date:** 2024-06

## 5 MAC Procedures

### 5.3 Measurement Gap Handling

#### 5.3.1 General

Measurement gaps are time intervals during which the UE performs inter-frequency and inter-RAT measurements. During a measurement gap, the UE is not expected to transmit or receive on the serving cell.

The measurement gap configuration is provided by RRC (TS 38.331 clause 5.5.4) and managed by the MAC layer for scheduling purposes.

#### 5.3.2 Gap Pattern Configuration

The following gap patterns are defined:

| Gap Pattern ID | MGL (ms) | MGRP (ms) | Gap Offset Range |
|---------------|-----------|------------|-----------------|
| 0 | 6 | 40 | 0..39 |
| 1 | 6 | 80 | 0..79 |
| 2 | 3 | 40 | 0..39 |
| 3 | 3 | 80 | 0..79 |

Where:
- MGL = Measurement Gap Length
- MGRP = Measurement Gap Repetition Period

#### 5.3.3 Pre-configured Measurement Gaps (Rel-18)

In Rel-18, pre-configured measurement gaps allow the network to configure measurement gaps in advance for predictable mobility scenarios. This reduces the latency of measurement gap activation from ~20ms to ~3ms.

**Procedure:**
1. Network configures pre-configured gap set via RRC (TS 38.331)
2. MAC entity stores gap configurations
3. Upon activation trigger (L1 indication), MAC activates the pre-configured gap
4. UE performs measurements during activated gap
5. Results reported via MeasurementReport (TS 38.331 clause 5.5.4)

#### 5.3.4 Concurrent Measurement Gaps

For FR1+FR2 dual connectivity scenarios, the UE may need concurrent measurement gaps on different frequency ranges. The MAC entity shall:

1. Prioritize gaps for the PCell frequency range
2. If gaps overlap, defer the SCG gap to the next occasion
3. Report gap collision to RRC for potential reconfiguration

#### 5.3.5 Interaction with DRX

When DRX is configured, measurement gaps interact with the DRX cycle:
- If a measurement gap overlaps with DRX ON duration, the UE prioritizes the measurement gap
- The UE shall not start a new DRX ON duration during an active measurement gap
- After the measurement gap ends, the UE resumes DRX operation

```asn1
-- ASN1START
MeasGapConfig ::= SEQUENCE {
    gapFR1 GapConfig OPTIONAL,
    gapFR2 GapConfig OPTIONAL,
    preConfiguredGaps PreConfiguredGapList OPTIONAL -- Rel-18
}

GapConfig ::= SEQUENCE {
    gapOffset INTEGER (0..159),
    mgl ENUMERATED {ms1dot5, ms3, ms3dot5, ms4, ms5dot5, ms6},
    mgrp ENUMERATED {ms20, ms40, ms80, ms160},
    mgta ENUMERATED {ms0, ms0dot25, ms0dot5}
}

PreConfiguredGapList ::= SEQUENCE (SIZE (1..8)) OF PreConfiguredGap

PreConfiguredGap ::= SEQUENCE {
    gapId INTEGER (0..7),
    gapConfig GapConfig,
    activationCondition ENUMERATED {l1-indication, timer-based}
}
-- ASN1STOP
```
