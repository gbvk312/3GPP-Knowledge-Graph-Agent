# TS 38.331 — NR; Radio Resource Control (RRC) protocol specification

**3GPP Release:** Rel-18
**Version:** 18.2.0
**Date:** 2024-06

## 5.5 Measurements

### 5.5.1 General

The UE shall perform measurements for the purposes of intra-frequency, inter-frequency, and inter-RAT mobility. Measurement configuration is provided by the network via dedicated RRC signalling.

The measurement framework defined in this section applies to measurements performed by the UE in RRC_CONNECTED state. For measurements in RRC_IDLE and RRC_INACTIVE, see TS 38.304 clause 5.2.4.

### 5.5.4 Measurement Reporting

#### 5.5.4.1 General

The purpose of this procedure is to transfer measurement results from the UE to the network. The UE shall initiate the measurement reporting procedure when reporting criteria are fulfilled for a measurement configured with report type set to eventTriggered or periodical.

**References:**
- Physical layer measurement quantities are defined in TS 38.213 clause 4.1
- MAC layer measurement gap configuration is specified in TS 38.321 clause 5.3
- Cell reselection measurement criteria are defined in TS 38.304 clause 5.2.4

#### 5.5.4.2 Initiation

The UE shall initiate the measurement reporting procedure when:
1. The entering condition for the configured event is met for the configured time-to-trigger (see clause 5.5.4.4)
2. The measurement identity is included in the measIdList
3. The corresponding measurement has not been deactivated

#### 5.5.4.3 Event-Triggered Reporting

The following events are defined for NR measurements:

| Event | Description | Condition |
|-------|-------------|-----------|
| A1 | Serving becomes better than threshold | Ms - Hys > Thresh |
| A2 | Serving becomes worse than threshold | Ms + Hys < Thresh |
| A3 | Neighbour becomes offset better than SpCell | Mn + Ofn + Ocn - Hys > Ms + Ofp + Ocp + Off |
| A4 | Neighbour becomes better than threshold | Mn + Ofn + Ocn - Hys > Thresh |
| A5 | SpCell worse than threshold1 AND neighbour better than threshold2 | Ms + Hys < Thresh1 AND Mn + Ofn + Ocn - Hys > Thresh2 |
| A6 | Neighbour becomes offset better than SCell | Mn + Ofn + Ocn - Hys > Ms + Ofp + Ocp + Off |

#### 5.5.4.4 Measurement Reporting Procedure

```asn1
-- ASN1START
MeasurementReport ::= SEQUENCE {
    criticalExtensions CHOICE {
        measurementReport MeasurementReport-IEs,
        criticalExtensionsFuture SEQUENCE {}
    }
}

MeasurementReport-IEs ::= SEQUENCE {
    measResults MeasResults,
    lateNonCriticalExtension OCTET STRING OPTIONAL,
    nonCriticalExtension SEQUENCE {} OPTIONAL
}

MeasResults ::= SEQUENCE {
    measId MeasId,
    measResultServingMOList MeasResultServMOList,
    measResultNeighCells CHOICE {
        measResultListNR MeasResultListNR,
        measResultListEUTRA MeasResultListEUTRA,
        ...
    } OPTIONAL,
    ...
}

MeasResultNR ::= SEQUENCE {
    physCellId PhysCellId OPTIONAL,
    measResult SEQUENCE {
        cellResults SEQUENCE {
            resultsSSB-Cell MeasQuantityResults OPTIONAL,
            resultsCSI-RS-Cell MeasQuantityResults OPTIONAL
        },
        rsIndexResults SEQUENCE {
            resultsSSB-Indexes ResultsPerSSB-IndexList OPTIONAL,
            resultsCSI-RS-Indexes ResultsPerCSI-RS-IndexList OPTIONAL
        } OPTIONAL
    },
    ...
}

MeasQuantityResults ::= SEQUENCE {
    rsrp RSRP-Range OPTIONAL,
    rsrq RSRQ-Range OPTIONAL,
    sinr SINR-Range OPTIONAL
}
-- ASN1STOP
```

#### 5.5.4.5 Actions upon Transmission

Upon transmitting the MeasurementReport message, the UE shall:
1. Increment the numberOfReportsSent for the corresponding measurement identity
2. Start timer T321 with the configured value
3. If the number of reports sent equals the configured reportAmount, consider the measurement reporting to be completed

### 5.5.5 Measurement Configuration (Rel-18 Enhancements)

#### Feature: Conditional Measurement Reporting

In Rel-18, conditional measurement reporting allows the UE to report measurements only when specific L1 conditions are met, reducing signalling overhead by up to 40%.

This feature supersedes the basic periodic reporting mechanism from Rel-15.

| Release | Feature | Status |
|---------|---------|--------|
| Rel-15 | Basic measurement reporting | Mandatory |
| Rel-16 | Early measurement reporting | Optional |
| Rel-17 | CHO measurement reporting | Optional |
| Rel-18 | Conditional measurement reporting | Optional |
