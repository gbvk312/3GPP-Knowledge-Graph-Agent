# TS 38.304 — NR; UE procedures in idle mode and RRC inactive state

**3GPP Release:** Rel-18
**Version:** 18.1.0
**Date:** 2024-06

## 5 Process and Procedure Descriptions

### 5.2 Cell Reselection

#### 5.2.4 Cell Reselection Criteria

##### 5.2.4.1 General

The UE shall perform cell reselection evaluation using measurements performed according to the measurement rules defined in this clause. The measurement quantities used for cell reselection are defined in TS 38.213 clause 4.1.

Cell reselection decisions are based on cell ranking using the R-criteria:

**Serving cell:**
```
Rs = Qmeas,s + QHyst
```

**Neighbour cell:**
```
Rn = Qmeas,n - Qoffset
```

Where:
- Qmeas = SS-RSRP measurement quantity (see TS 38.213 clause 4.1)
- QHyst = hysteresis value for ranking
- Qoffset = offset between serving and neighbour cell

##### 5.2.4.2 Intra-frequency Cell Reselection

For intra-frequency cell reselection, the UE shall:
1. Measure SS-RSRP of detected intra-frequency neighbour cells
2. Apply Layer 3 filtering (filter coefficient from SIB3/SIB4)
3. Evaluate ranking criterion: reselect to neighbour if Rn > Rs for Treselection duration
4. Upon reselection, report to NAS and acquire system information of target cell

The measurement reporting for connected mode uses the framework in TS 38.331 clause 5.5.4.

##### 5.2.4.3 Inter-frequency Cell Reselection

Inter-frequency cell reselection requires measurement gaps in idle mode. The UE shall:
1. Perform inter-frequency measurements when serving cell quality < SnonIntraSearchP
2. Measure SS-RSRP and SS-RSRQ on configured inter-frequency layers
3. Apply frequency-specific offset (Qoffsetfreq) to ranking
4. Evaluate S-criteria: Srxlev > 0 AND Squal > 0

Priority-based reselection:
- Higher priority layers: measure regardless of serving cell quality
- Lower priority layers: measure only when serving cell quality < ThreshServing,LowP

##### 5.2.4.4 Relaxed Measurements (Rel-18)

In Rel-18, relaxed measurement criteria allow the UE to reduce measurement frequency when:
- Serving cell quality is above a configured threshold (SSearchDeltaP)
- UE is stationary (low mobility state detected)
- No higher priority layers are configured

This reduces UE power consumption by up to 30% in stable radio conditions.

| Condition | Measurement Relaxation |
|-----------|----------------------|
| High serving cell quality | Extend measurement cycle by 2x |
| Stationary UE | Extend measurement cycle by 4x |
| Both conditions met | Extend measurement cycle by 6x |

The relaxed measurement parameters are broadcast in SIB2 and can be overridden by dedicated signalling via TS 38.331.

##### 5.2.4.5 Measurement Rules

The UE shall measure:
- Intra-frequency: at least every DRX cycle (or Tmeasure if configured)
- Inter-frequency higher priority: at least every 60s × Nlayers
- Inter-frequency lower priority: at least every 60s × Nlayers (when triggered)

```asn1
-- ASN1START
-- Cell reselection parameters from SIB2/SIB3
CellReselectionServingFreqInfo ::= SEQUENCE {
    sNonIntraSearchP ReselectionThreshold OPTIONAL,
    sNonIntraSearchQ ReselectionThresholdQ OPTIONAL,
    threshServingLowP ReselectionThreshold,
    cellReselectionPriority CellReselectionPriority,
    cellReselectionSubPriority CellReselectionSubPriority OPTIONAL
}

CellReselectionInfoCommon ::= SEQUENCE {
    qHyst ENUMERATED {dB0, dB1, dB2, dB3, dB4, dB5, dB6, dB8,
                      dB10, dB12, dB14, dB16, dB18, dB20, dB22, dB24},
    speedStateReselectionPars SEQUENCE {
        mobilityStateParameters MobilityStateParameters,
        qHystSF SpeedStateScaleFactors
    } OPTIONAL,
    -- Rel-18 relaxed measurement
    relaxedMeasCondition ENUMERATED {lowMobility, cellEdge, both} OPTIONAL
}
-- ASN1STOP
```
